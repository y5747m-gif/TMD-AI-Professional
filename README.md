# مشكاة — Mishkat

> **مساعد للأسئلة الدينية: يردّ بجوابٍ منقولٍ من موقع «إسلام ويب» (فتاوى/استشارات/مقالات) مع رقمه ورابطه، ويعرض روابط الفيديوهات المتعلقة بالسؤال — بلا أي نسخ كامل لنصوص الفيديوهات.**

القناة المعتمدة (تُستعمل للعرض وربط الفيديوهات فقط): [`UCv0g_v1C6JcZALvrkDu98AQ`](https://www.youtube.com/channel/UCv0g_v1C6JcZALvrkDu98AQ) — «تعلم دينك لتنجو وتسعد».

---

## ١) ما الذي تغيّر في هذه النسخة (2.0)؟

| قبل | بعد |
| --- | --- |
| سحب نصوص الفيديوهات (Ingest) وتخزين تفريغاتها كاملة في قاعدة بيانات | **أُزيل تمامًا**: لا سحب من يوتيوب، ولا تخزين لأي نص فيديو |
| الرد يُبنى من مقاطع نصّ الفيديو | **الرد يُجلب من موقع إسلام ويب** بنصّه الكامل مع الرقم والرابط |
| واجهة تعرض «النص الكامل» للفيديو | روابط الفيديوهات المتعلقة بالسؤال فقط (عنوان + رابط) |
| قاعدة بيانات SQLite + فهرسة FTS | ملف لائحة واحد: `mishkat/data/videos.json` |

النتيجة: أداة أخفّ، تردّ بالنصّ الشرعي الموثّق من مصدره، وتفتح للزائر روابط الدروس المرتبطة بسؤاله.

---

## ٢) كيف يعمل؟

1. **يفهم السؤال** ويستخرج كلماته الفقهية الجوهرية (تطبيع همزات/تشكيل + مرادفات شرعية + استبعاد كلمات الاستفهام).
2. **يبحث في إسلام ويب** في ثلاثة أقسام: **الفتاوى + الاستشارات + المقالات**.
3. **يرتّب النتائج**: ترتيب لغوي محلي (تغطية الكلمات في العنوان والمقتطف)، وإن وُجد مفتاح ذكاء اصطناعي يُستخدم أيضًا لاختيار أدقّ مصدر.
4. **يجلب النصّ الكامل** لأفضل مصدر (السؤال والجواب كما هما في الموقع).
5. **يعرض الروابط**: أعلى المصادر مع أرقامها وروابطها، وروابط الفيديوهات المتعلقة بالسؤال.
6. **الصياغة**: إمّا نقل حرفي (افتراضي)، وإمّا إعادة تنظيم بالذكاء الاصطناعي **دون أي إضافة حكم من عنده**.

> **قاعدة صارمة داخل الأداة:** لا يضيف المحرك الذكي حكمًا ولا دليلًا ولا قولًا لعالمٍ غير موجود في نصّ المصدر. مهمته: تنظيم، وترتيب، وتوضيح لغوي فقط.

## ٣) التشغيل السريع

```bash
# ١) شغّل الواجهة (بلا أي مكتبات خارجية — Node.js 20+)
npm start                     # أو: node mishkat/server.js

# ٢) افتح الواجهة
#    http://localhost:3000
```

ثم:

```bash
# أضف روابط فيديوهات القناة (عنوان + رابط) — اليدوي أو بالمرة
npm run video:add -- --url "https://www.youtube.com/watch?v=xxxxxxxxxxx" --title "أحكام زكاة الفطر" --tags "زكاة، فقه"
npm run videos                # لعرض اللائحة
```

وتشغيل المحرك الذكي (اختياري تمامًا):

```bash
cp .env.example .env          # ثم ضع مفتاحًا واحدًا مثل GEMINI_API_KEY
```

> الأداة تعمل كاملة **بلا أي مفتاح**: في هذه الحالة تُنقل الردود من إسلام ويب كما هي مع روابطها.

## ٤) وضعا الرد

| الوضع | الوصف | متى يُستعمل |
| --- | --- | --- |
| `sources` — نقل كما هو | يُعرض جواب إسلام ويب بنصّه، مع رقم الفتوى ورابطها واسم القسم | الافتراضي، ويعمل بلا مفتاح |
| `composed` — صياغة منظّمة | يعيد المحرك الذكي ترتيب النصّ في خلاصة ونقاط، منقولًا من المصادر نفسها | عند وجود مفتاح API، ويمكن اختياره من الواجهة |

في كلا الوضعين: **المصادر تُعرض دائمًا** (فتوى/استشارة/مقال + الرقم + الرابط)، وروابط الفيديوهات تُرفق في نهاية الرد.

## ٥) لائحة الفيديوهات (روابط فقط)

اللائحة في ملف واحد: [`mishkat/data/videos.json`](mishkat/data/videos.json)

```json
{
  "format": "mishkat-videos/v1",
  "channel": { "id": "UCv0g_v1C6JcZALvrkDu98AQ", "title": "تعلم دينك لتنجو وتسعد" },
  "videos": [
    {
      "id": "xxxxxxxxxxx",
      "title": "أحكام زكاة الفطر ومقدارها",
      "url": "https://www.youtube.com/watch?v=xxxxxxxxxxx",
      "description": "درس مختصر في فقه الزكاة",
      "tags": ["زكاة", "فقه", "صيام"]
    }
  ]
}
```

طرق الإضافة:

| الطريقة | الأمر |
| --- | --- |
| فيديو واحد برابطه (يجلب العنوان تلقائيًا) | `npm run video:add -- --url "<الرابط>"` |
| فيديو بعنوان ووسوم | `npm run video:add -- --url "<الرابط>" --title "..." --tags "فقه، صلاة"` |
| استيراد لائحة من ملف نصّي | `npm run video:import -- --file videos.txt` |
| حذف فيديو | `npm run video:rm -- --id <معرّف الفيديو>` |
| من المتصفح | لوحة الإدارة (زر ⚙) — إضافة، استيراد، تشخيص |

صيغ ملف الاستيراد المقبولة (سطر لكل فيديو):

```
عنوان الدرس | https://www.youtube.com/watch?v=xxxxxxxxxxx
https://youtu.be/yyyyyyyyyyy | عنوان آخر
https://www.youtube.com/watch?v=zzzzzzzzzzz
```

> نصيحة: الوسوم (`tags`) ترفع دقة ربط السؤال بالفيديو كثيرًا، فاجعلها كلمات فقهية مباشرة (زكاة، صلاة، طلاق، ربا…).

## ٦) محرك الذكاء الاصطناعي (اختياري)

* **بلا مفتاح:** وضع «نقل كما هو» — لا يُستدعى أي مزوّد خارجي.
* **بمفتاح:** يُستخدم في أمرين فقط:
  1. **ترتيب المصادر** واختيار أدقّها للسؤال (بلا اختراع مصادر).
  2. **صياغة الرد** تنظيمًا وتوضيحًا من نصوص المصادر.

المزوّدون المدعومون (يُختار الأول المتاح تلقائيًا، ويمكن تثبيت واحد بـ `MISHKAT_AI_MODE`):

| المزوّد | المفتاح | الموديل الافتراضي |
| --- | --- | --- |
| Google Gemini | `GEMINI_API_KEY` | `gemini-2.0-flash` |
| Groq | `GROQ_API_KEY` | `openai/gpt-oss-120b` |
| OpenAI | `OPENAI_API_KEY` | `gpt-4o-mini` |
| OpenRouter | `OPENROUTER_API_KEY` | `google/gemini-2.0-flash-001` |
| أي مزوّد متوافق | `MISHKAT_LLM_BASE_URL` + `MISHKAT_LLM_API_KEY` | `MISHKAT_LLM_MODEL` |

للتعطيل الكامل: `MISHKAT_AI_MODE=off`.

## ٧) الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `npm start` | تشغيل الواجهة والخادم |
| `npm run ask -- "ما حكم زكاة الفطر؟"` | سؤال من سطر الأوامر (`--mode composed`) |

| `npm run stats` | إحصاءات اللائحة والذاكرة المؤقتة والمحرك |
| `npm run doctor [-- --probe]` | فحص التشغيل (`--probe` يجرّب الاتصال بإسلام ويب) |
| `npm run cache:clear` | تفريغ الذاكرة المؤقتة للصفحات |
| `npm test` | تشغيل الاختبارات |

## ٨) واجهة HTTP

| الطريقة | المسار | الوصف |
| --- | --- | --- |
| `GET` | `/api/health` | حالة الأداة (المصدر، الفيديوهات، المحرك) |
| `GET` | `/api/config` | الإعدادات والأوضاع والاقتراحات |
| `GET` | `/api/stats` | إحصاءات اللائحة والذاكرة المؤقتة |
| `POST` | `/api/ask` | السؤال: `{ question, mode, history, stream }` — بثّ SSE أو JSON |
| `POST` | `/api/search` | بحث بلا صياغة: مصادر + فيديوهات |
| `GET` | `/api/videos` | لائحة الروابط (`?q=` للبحث) |
| `POST` | `/api/videos` | إضافة/تحديث فيديو (يتطلب `MISHKAT_ADMIN_TOKEN` إن كان مفعّلًا) |
| `DELETE` | `/api/videos?id=<id>` | حذف فيديو (يتطلب المدير) |
| `GET` | `/api/diagnose` | فحص شامل (`?probe=1` لفحص الشبكة) |
| `GET` | `/videos.json` | اللائحة الخام كما في الملف |

بثّ `/api/ask`: يبدأ الحدث `meta` (المصادر والروابط) ثم `token` للنصّ ثم `done`.

## ٩) النشر على Vercel

```bash
vercel --prod
```

* دالة واحدة: [`api/index.js`](api/index.js) (حدّ Hobby) تستدعي [`mishkat/lib/vehand.js`](mishkat/lib/vehand.js).
* إعادة الكتابة في [`vercel.json`](vercel.json): `/api/(.*)` → `/api/index?path=$1`، والملفات الثابتة من `mishkat/public`.
* النسخة المنشورة **للقراءة فقط** للائحة الفيديوهات (نظام ملفات Vercel غير قابل للكتابة): أضف الروابط محليًا ثم `git push`.

## ١٠) كيف نتعامل مع إسلام ويب؟

| الخطوة | التفصيل |
| --- | --- |
| البحث | `/ar/fatwa/?page=websearch&stxt=<الكلمات>` — وكذلك `/ar/consult/` و`/ar/articles/index.php` |
| صفحة الوثيقة | `/ar/fatwa/<رقم>/` و`/ar/consult/<رقم>/` و`/ar/article/<رقم>/` |
| الاستخراج | عنوان الصفحة + **السؤال** + **الإجابــة** + التاريخ الهجري/الميلادي + اسم المجيب + مسار التصنيف |
| الاحتياط | إن حجب الخادم الاتصال المباشر (403/مهلة) يُستعمل قارئ صفحات نصّي `ISLAMWEB_READER_BASE` تلقائيًا |
| التخزين المؤقت | في الذاكرة ولمدة قابلة للضبط (`ISLAMWEB_CACHE_TTL_MINUTES`) لتقليل الطلبات |

**سياسة الاستخدام:** تُنقل النصوص مع ذكر القسم ورقم الوثيقة ورابطها الأصلي، ولا تُخزَّن نسخة دائمة من محتوى الموقع في المستودع (الذاكرة المؤقتة داخل `mishkat/data/cache/` ومستثناة من Git).

## ١٣) حلّ المشكلات

| المشكلة | الحل |
| --- | --- |
| «لم أجد ردًّا في إسلام ويب» | أعد صياغة السؤال بكلمات فقهية مباشرة (مثال: «زكاة الفطر»، «يمين الطلاق») |
| «تعذّر الوصول إلى موقع إسلام ويب» | تحقّق من الشبكة، أو اجعل `ISLAMWEB_MODE=auto` لتفعيل القارئ الاحتياطي |
| الرد بطيء | قلّل `ISLAMWEB_FULL_DOCS` أو `ISLAMWEB_TOP_K` |
| لا تظهر فيديوهات | اللائحة فارغة — أضف روابط: `npm run video:add -- --url "<رابط>"` |
| الفيديو خاطئ أو غير مرتبط | أضف وسومًا دقيقة للفيديو (`--tags`) |
| «تعذّر الكتابة على ملف اللائحة» | أنت على نشر للقراءة فقط — أضف الروابط محليًا ثم ارفع التغيير |
| المسارات القديمة (`/api/ingest` …) | أُلغيت، وتُرجع رسالة توضيحية بدل خطأ — راجع `/api/health` |

## ١٤) ملاحظات

* لا تُخزَّن نصوص الفيديوهات ولا تفريغاتها في أي مكان من الأداة، ولا يوجد أمر سحب من يوتيوب.
* الردود مِلكٌ لأصحابها في موقع إسلام ويب، وتُنقل موثّقةً برقمها ورابطها.
* الأداة أداة بحثٍ وعرضٍ للسؤال والجواب، وليست جهة فتوى؛ وفي النوازل الشخصية يُسأل أهل العلم مباشرة.

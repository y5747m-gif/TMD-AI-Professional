# مشكاة — Mishkat

> **أداة ذكاء اصطناعي احترافية للإجابة على الأسئلة الدينية من نصوص قناة علمية على يوتيوب**
> تعرض النص المستخرَج، وتوقيته، ورابط الفيديو المتعلق بسؤال المستخدم — مع قاعدة بيانات محلية ومحرك ذكاء اصطناعي منفصل قابل للتبديل.

القناة المعتمدة: [`UCv0g_v1C6JcZALvrkDu98AQ`](https://youtube.com/channel/UCv0g_v1C6JcZALvrkDu98AQ) — ثابتة داخل الأداة في كل مكان.

---

## ١) ما الذي تفعله الأداة؟

1. **تسرد** كل فيديوهات القناة.
2. **تستخرج النصوص** (الترجمة/التفريغ) لكل فيديو.
3. **تنظّف** النص وتقسّمه إلى مقاطع زمنية (Chunks) تحمل توقيت البداية والنهاية.
4. **تفهرسها** في قاعدة بيانات محلية (SQLite + FTS5 عربي).
5. **تبحث** بحثًا هجينًا (مرادفات شرعية + تطبيع همزات/تشكيل + إعادة ترتيب حسب تغطية كلمات السؤال).
6. **تجيب** بمحرك ذكاء اصطناعي منفصل (Gemini / Groq / OpenAI / OpenRouter / أي مزوّد متوافق)، أو بمحرك استخراجي مبني على النص مباشرة إن لم يوجد مفتاح API.
7. **توثّق الإجابة**: تُرفق كل فقرة بمصدرها `[المصدر 1]` + التوقيت `02:15` + رابط يفتح الفيديو عند اللحظة نفسها.
8. **توسّع المجال**: ثلاثة أوضاع للإجابة — صارم، متوازن، وواسع المجال (استفاضة في المسائل المتصلة والمذاهب والنوازل).

## ٢) التشغيل السريع (ثلاث خطوات)

```bash
# ١) تشغيل الواجهة (لا يحتاج أي تثبيت مكتبات)
npm start                # أو: node mishkat/server.js

# ٢) في نافذة أخرى: سحب نصوص القناة إلى قاعدة البيانات
npm run ingest           # كل الفيديوهات — أو: npm run ingest -- --limit 20

# ٣) تشغيل المحرك الذكي (اختياري — الأداة تعمل بدونه)
cp .env.example .env     # ثم ضع مفتاحًا واحدًا مثل GEMINI_API_KEY
```

ثم افتح: <http://localhost:3000>

> مهم: أمر السحب `npm run ingest` يجب أن يُشغَّل على جهاز متصل بالإنترنت (جهازك أو أي خادم).
> بعض البيئات المغلقة (Sandbox) لا تسمح بالوصول إلى youtube.com، ولذلك تظهر الواجهة ببيانات تجريبية حتى تسحب النصوص الحقيقية.

## ٣) قاعدة البيانات (سحب نصوص القناة)

| الأمر | الوظيفة |
| --- | --- |
| `npm run ingest` | سحب كل فيديوهات القناة (تخطّي الموجود) |
| `npm run ingest -- --limit 20` | سحب أول 20 فيديو فقط (تجربة سريعة) |
| `npm run ingest -- --video <ID>` | سحب فيديو واحد بالمعرّف |
| `npm run ingest:force` | إعادة سحب الكل من جديد |
| `npm run stats` | إحصاءات القاعدة (فيديوهات/مقاطع/أحرف/ساعات) |
| `npm run videos` | سرد الفيديوهات المفهرسة |
| `npm run export` | تصدير نسخة `mishkat/data/index.json` (للنشر أو النسخ الاحتياطي) |
| `npm run purge-demo` | حذف البيانات التجريبية |
| `npm run doctor` | فحص شامل للتشغيل (الإصدار، الشبكة، القاعدة، المفاتيح) |
| `npm test` | تشغيل 69 اختبارًا (وحدات + خادم + تكامل شامل + مسارات Vercel) |

**بدون مفتاح YouTube:** الأداة تسرد الفيديوهات وتستخرج النصوص باستخراج مباشر من واجهة يوتيوب.
**مع مفتاح YouTube Data API** (`YOUTUBE_API_KEY`): سرد أسرع وأدق مع المدة وعدد المشاهدات.

يمكن ضبط دقة التقسيم عبر `MISHKAT_CHUNK_CHARS` (الافتراضي 300 حرف — أي نحو 20-40 ثانية من الكلام)،
وكلما صغُر المقاطع دقّ توقيت الاستشهاد. وتُدمج المقاطع المتجاورة تلقائيًا عند عرض الإجابة لاستعادة السياق.

ملاحظة: الفيديوهات التي لا تحتوي ترجمة/تفريغًا على يوتيوب لا يمكن فهرستها؛ تُسجَّل في القاعدة مع سبب واضح، ويُمكن تفعيل `MISHKAT_USE_YTDLP=true` لاستخدام `yt-dlp` كبديل.

## ٤) محرك الذكاء الاصطناعي (منفصل وقابل للتبديل)

ضع **مفتاحًا واحدًا** في `.env` ويعمل المحرك تلقائيًا:

```bash
MISHKAT_AI_MODE=auto          # auto | gemini | groq | openai | openrouter | custom | off

GEMINI_API_KEY=...            # GEMINI_MODEL=gemini-2.0-flash
GROQ_API_KEY=...              # GROQ_MODEL=openai/gpt-oss-120b
OPENAI_API_KEY=...            # OPENAI_MODEL=gpt-4o-mini
OPENROUTER_API_KEY=...        # OPENROUTER_MODEL=google/gemini-2.0-flash-001
MISHKAT_LLM_BASE_URL=...      # أي مزوّد متوافق مع OpenAI
```

* **بدون أي مفتاح**: تعمل الأداة بـ«المحرك الاستخراجي» — تعرض أقرب النصوص مع التوقيت والروابط، وتوسّم مسائل التوسّع بوضوح.
* **مع مفتاح**: يجيب المحرك الذكي وفق منهجية علمية صارمة: خلاصة ← تحرير المسألة ← الأدلة من النصوص المرفقة ← أقوال أهل العلم ← مسائل متصلة وتوسّع ← تنبيهات.
* الإجابة تُبَثّ **مباشرة (Streaming/SSE)** حرفًا بحرف، وإن تعذّر البث تعود الواجهة تلقائيًا للوضع غير المتدفق.

### أوضاع اتساع الإجابة

| الوضع | السلوك |
| --- | --- |
| `strict` (صارم) | لا يجيب إلا بنصوص القناة، ويصرّح عند عدم وجود نص. |
| `balanced` (متوازن — الافتراضي) | النصوص أساسًا + مسائل متصلة موسومة أنها للاستزادة. |
| `open` (واسع المجال) | استفاضة موسوعية: المذاهب، القواعد، المقاصد، الفروق، النوازل المعاصرة، وتطبيقات عملية — مع تمييز صريح لما ليس من نصوص القناة. |

## ٥) واجهات الاستخدام

### أ) الواجهة الرسومية
* **شريط جانبي**: اختيار وضع الإجابة، بدايات سريعة، مكتبة الفيديوهات مع البحث، حالة القاعدة.
* **المحادثة**: إجابة متدفقة، بطاقات مصادر مرقّمة (التوقيت + الرابط + نسبة الصلة)، نسخ الإجابة، إعادة الصياغة، محادثة جديدة.
* **نافذة الفيديو**: التفريغ الكامل بالتوقيتات، بحث داخل النص، وزر **✨ تلخيص الدرس**.
* **لوحة الإدارة (⚙)**: سحب القناة أو إضافة فيديو واحد، مع سجل تقدّم مباشر، وحذف البيانات التجريبية.

### ب) سطر الأوامر
```bash
node mishkat/cli.js ask "ما حكم صلاة الجماعة؟" --mode open
node mishkat/cli.js search "زكاة الفطر" --topK 8
node mishkat/cli.js video <videoId> --q "النية"
node mishkat/cli.js add-doc --title "قاعدة فقهية" --text "..." --ref "..."
```

### ج) HTTP API
| المسار | الوصف |
| --- | --- |
| `GET /api/health` | حالة الخدمة والقاعدة |
| `GET /api/config` | إعدادات الواجهة + محرك الذكاء + القناة + الإحصاءات |
| `GET /api/stats` | إحصاءات القاعدة وسجل الأحداث |
| `POST /api/ask` | `{ message, mode, history, stream }` — إجابة (SSE أو JSON) |
| `POST /api/search` | `{ query, topK }` — نصوص فقط مع التوقيت والروابط |
| `GET /api/videos?q=&limit=` | قائمة الفيديوهات المفهرسة |
| `GET /api/video?id=<ID>&q=` | التفريغ الكامل أو البحث داخله (وتعمل أيضًا صيغة `/api/video/<ID>`) |
| `POST /api/summarize` | `{ videoId }` — تلخيص الدرس |
| `POST /api/ingest` | سحب القناة/فيديو (يتطلب `MISHKAT_ADMIN_TOKEN`) مع بثّ التقدّم |
| `POST /api/purge-demo` | حذف البيانات التجريبية (يتطلب المدير) |

## ٦) نشر الواجهة على Vercel (اختياري)

بيئة Vercel **للقراءة فقط**، لذلك:

1. اسحب النصوص محليًا: `npm run ingest`
2. صدّر النسخة المفهرسة: `npm run export` → `mishkat/data/index.json`
3. ارفع المستودع إلى GitHub واربطه بـ Vercel، واضبط متغيّرات البيئة (مفتاح المزوّد + `YOUTUBE_CHANNEL_ID`).
4. `vercel.json` يقدّم الواجهة من `mishkat/public` ويضمّن ملف الفهرس مع الدوال:

```
api/health.js    api/config.js   api/stats.js    api/videos.js  api/video.js
api/ask.js       api/search.js   api/summarize.js api/suggest.js
api/ingest.js    api/purge-demo.js   ← تُرجع 501 بشرح واضح (السحب محلي فقط)
```

كل ملف سطران فقط، والمنطق كله في `mishkat/lib/vehand.js` — فلا حاجة إلى إعادات كتابة (rewrites) هشّة.

> ملاحظة: النسخة المنشورة **للقراءة فقط**: لا تدعم السحب (Ingest) ولا تعديل قاعدة البيانات؛
> حدّث البيانات بالسحب محليًا ثم أعد نشر `index.json`.

## ٧) التحقق من الجودة (٦٩ اختبارًا ناجحًا)

```bash
npm test        # 69/69 ✅
```

* **اختبارات الوحدات**: تطبيع العربية، المرادفات، التصنيف، تحليل الترجمات (json3/srv3)،
  تنظيف التكرار، تقسيم المقاطع، الروابط والتوقيتات.
* **اختبارات الخادم**: كل مسارات API، البثّ SSE، حماية المسارات، صلاحيات المدير، المتجر البديل.
* **اختبار مسارات Vercel** (`mishkat/test/vercel.test.js`): يستدعي ملفات `api/*.js` نفسها
  عبر خادم يحاكي بيئة Serverless، ويتأكد من أن كل مسار في الواجهة له ملف مقابل في `api/`
  وأن النسخة المنشورة (القراءة فقط) تعمل.
* **اختبار تكاملي شامل** (`mishkat/test/e2e.test.js`): يُشغّل خادمًا محليًا **يحاكي يوتيوب**
  (صفحة القناة + متابعة التحميل + واجهة المشغّل + ملف الترجمة) وخادمًا **يحاكي مزوّد الذكاء الاصطناعي**،
  ثم يُنفّذ المسار كاملًا:
  `سرد القناة ← استخراج النصوص ← التنظيف والتقسيم ← الفهرسة ← الاسترجاع ← الإجابة المتدفقة`
  ويتأكد من: مطابقة التوقيت في الرابط، ووصول المصادر المرقّمة والروابط إلى المحرك الذكي،
  وصحة التلخيص، وصلاحية ملف `index.json` للنشر، والعمل عبر HTTP API.

> هذا الاختبار يثبت أن الأداة تعمل فعليًا بلا إنترنت ولا مفاتيح — قبل سحب بيانات قناتك.

## ٨) كيف تعمل الأداة (خط الأنابيب)

```
قناة يوتيوب
   │  (سرد: YouTube Data API أو استخراج مباشر)
   ▼
بيانات الفيديو ────────────────────────────────┐
   │  (استخراج النص: InnerTube → صفحة المشاهدة → yt-dlp)
   ▼                                            │
تنظيف النص (إزالة [موسيقى]، تكرار الترجمة التلقائية)│
   │                                            │
تقسيم إلى مقاطع (Chunk ~700 حرف + تداخل + حدود زمنية)
   │                                            │
فهرسة SQLite + FTS5 (مع بديل JSON)  ◄───────────┘
   │
استرجاع هجين: FTS(AND) → FTS(OR) → LIKE
   │              + تطبيع عربي + مرادفات شرعية + تجذيع خفيف
   ▼
إعادة ترتيب: تغطية كلمات السؤال + صلة الفئة + مطابقة العنوان + دمج المقاطع المتجاورة
   │
   ▼
بناء السياق المرقّم [المصدر 1..N] (بالتوقيت والرابط)
   │
   ├──► محرك ذكاء اصطناعي (بثّ مباشر)  ──► إجابة موثّقة موسّعة
   └──► محرك استخراجي (بدون مفتاح)      ──► نص + مصادر + مسائل متصلة
```

## ١٠) استكشاف الأخطاء

| المشكلة | الحل |
| --- | --- |
| القاعدة فارغة / لا نتائج | شغّل `npm run ingest` على جهاز متصل بالإنترنت |
| «تعذّر جلب النص» لكثير من الفيديوهات | الفيديو بلا ترجمة على يوتيوب؛ جرّب `MISHKAT_USE_YTDLP=true` مع تثبيت `yt-dlp` |
| تنبيه `SQLite is an experimental feature` | تنبيه فقط من Node، وليس خطأ؛ أو استخدم `MISHKAT_STORE=json` |
| الإجابة استخراجية فقط | لا يوجد مفتاح API — أضف مفتاحًا في `.env` ثم أعد التشغيل |
| لا يعمل السحب من داخل بيئة معزولة | شغّل السحب على جهازك ثم انسخ `mishkat/data/index.json` |
| ظهور «بيانات تجريبية» | بيانات توضيحية بحتة: `npm run purge-demo` أو نفّذ سحبًا حقيقيًا (تُحذف تلقائيًا) |

## ١١) ملاحظات شرعية وقانونية

* الأداة **وسيلة عرض وتوثيق للنصوص**، وليست جهة إفتاء رسمية، ولا تصدر فتاوى في النوازل الشخصية.
* كل إجابة تُحال إلى نص القناة وتوقيته ورابطه؛ وما ليس من نصوص القناة يُوسَم صراحةً أنه للاستزادة.
* عند المسائل الشخصية أو الخصومات أو المسائل المستجدة، يُرجَع إلى مفتٍ متخصص.
* المحتوى العلمي ملكٌ لأصحاب القناة، والأداة تستشهد بالمصدر وتُعيد الرابط الأصلي، ويُرجى مراعاة شروط استخدام القناة.
* النسخة القديمة من المشروع (كانت ببيانات وهمية) نُقلت إلى `legacy/tmd-v1/` للرجوع فقط، ولم يعد يعتمد عليها أي شيء في المسار الحالي — يمكن حذف المجلد بأمان: `rm -rf legacy/tmd-v1`.
